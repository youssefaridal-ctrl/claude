# مطبخي 3D — Kitchen 3D Designer

تطبيق موبايل (Android و iOS عبر Expo/React Native) يتيح للمستخدم إدخال مقاسات مطبخه
(الطول والعرض) يدويًا أو عبر رسم مخطط مصغر، ثم اختيار شكل المطبخ والستايل والألوان
والخامات، ومشاهدة النتيجة كمطبخ ثلاثي الأبعاد تفاعلي (Three.js) قابل للتدوير والتكبير،
وأخيرًا عرض ملخص التصميم مع تقدير تكلفة تقريبي.

## الشاشات

1. **الترحيب** (`app/index.tsx`) — تعريف بالتطبيق وبدء التصميم.
2. **الأبعاد** (`app/measurements.tsx`) — إدخال يدوي بالأرقام، أو رسم مخطط على شبكة
   (كل مربع = 20/30/40 سم قابل للاختيار) لتحديد الطول والعرض عبر السحب.
3. **الخيارات** (`app/options.tsx`) — شكل المطبخ (خط واحد / ممر / L / U / جزيرة)،
   الستايل (عصري / كلاسيكي / خشبي / مينيمال / صناعي)، ألوان الخزائن، خامة الكاونتر،
   الأرضية، لون الحائط، والأجهزة.
4. **المعاينة ثلاثية الأبعاد** (`app/preview.tsx`) — مشهد Three.js يُبنى إجرائيًا بناءً
   على الأبعاد والخيارات المختارة، مع إمكانية تبديل الشكل/الستايل مباشرة ورؤية التحديث فورًا.
5. **الملخص** (`app/summary.tsx`) — الأبعاد، المساحة، الخيارات المختارة، تقدير تكلفة
   تقريبي، ومشاركة التصميم.

## البنية التقنية

- **Expo (React Native) + TypeScript + expo-router** — تطبيق واحد يعمل على Android
  و iOS وويب.
- **Zustand** — حالة تصميم المطبخ مشتركة بين الشاشات (`src/store/kitchenStore.ts`).
- **Three.js** مُجمَّع بالكامل offline عبر esbuild إلى ملف HTML واحد
  (`src/generated/kitchen3dHtml.ts`، يُولَّد من `assets/web/kitchen3d/src/scene.ts`)
  ويُعرض داخل `react-native-webview` على الموبايل، أو `iframe` على الويب — بدون أي
  اتصال إنترنت مطلوب أثناء التشغيل.
- **react-native-svg** لواجهة رسم المخطط المصغر (Sketch pad).

## التشغيل

```bash
npm install
npm run build:kitchen3d   # يبني/يحدّث حزمة الـ 3D (شغّلها بعد أي تعديل على scene.ts)
npm run web               # تجربة سريعة في المتصفح
npm run android           # يتطلب Android Studio/محاكي أو جهاز حقيقي
npm run ios               # يتطلب macOS + Xcode
```

أي تعديل على `assets/web/kitchen3d/src/scene.ts` أو `template.html` يتطلب إعادة تشغيل
`npm run build:kitchen3d` لتحديث `src/generated/kitchen3dHtml.ts`.
