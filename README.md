# 📚 مكتبة النخبة — ملخصات أفضل 20 كتاباً في التنمية البشرية

موقع عربي ثابت (HTML/CSS/JS خالص — بلا أي إطار عمل) يقدّم ملخصات وافية لأفضل عشرين كتاباً
عالمياً في التنمية البشرية وتطوير الذات، بتصميم فاخر متجاوب (كحلي × ذهبي) واتجاه RTL كامل.

## ✨ المحتوى والمزايا

- **20 صفحة كتاب** لكل منها رابط مستقل: غلاف مصمم بالCSS، بطاقة معلومات (المؤلف، السنة،
  الصفحات، التصنيف، زمن القراءة، التقييم)، نبذة وافية عن الكاتب، ملخص مفصّل بأقسام مبوّبة،
  أهم 10 دروس عملية، اقتباسات مختارة، «لمن هذا الكتاب؟»، خطوة «ابدأ اليوم»، وخلاصة نهائية.
- صفحة رئيسية بشبكة كتب قابلة للتصفية حسب 7 تصنيفات + بحث بصري بالأغلفة.
- شريط تقدم قراءة، جدول محتويات جانبي، ملخصات ذات صلة، تنقل سابق/تالي بين الكتب.
- **جاهز لشركات الإعلانات (AdSense وغيرها):** من نحن، اتصل بنا، سياسة خصوصية شاملة
  (كوكيز + إعلانات الطرف الثالث)، شروط الاستخدام، إخلاء المسؤولية، صفحة 404،
  `sitemap.xml`، `robots.txt`، قالب `ads.txt`، ومساحات إعلانية مهيأة في التصميم.
- **SEO كامل:** عناوين ووصف لكل صفحة، Canonical، Open Graph، Twitter Cards،
  وبيانات منظمة JSON-LD (WebSite + Article + Book).

## 🗂️ البنية

```
├── index.html              الصفحة الرئيسية
├── about.html / contact.html / privacy-policy.html / terms.html / disclaimer.html / 404.html
├── books/                  صفحات الكتب العشرين (مولّدة — لا تحررها يدوياً)
├── content/                نص ملخص كل كتاب (حرّر هنا)
├── scripts/
│   ├── books.json          بيانات الكتب (العناوين، المؤلفون، التصنيفات، الروابط ذات الصلة…)
│   ├── template.html       قالب صفحة الكتاب
│   └── build.py            المولّد: يبني books/*.html و sitemap.xml
├── css/style.css           التصميم الكامل
└── js/main.js              التفاعلات (قائمة الجوال، الفلاتر، شريط التقدم…)
```

## 🔧 التعديل وإعادة البناء

لتعديل ملخص: حرّر `content/<slug>.html` ثم شغّل:

```bash
python3 scripts/build.py
```

لإضافة كتاب جديد: أضف مدخلاً في `scripts/books.json` + ملف محتوى في `content/`
+ بطاقة في `index.html`، ثم أعد البناء.

## 🚀 النشر

الموقع ثابت 100% ويعمل على أي استضافة:

- **GitHub Pages:** ‏Settings ← Pages ← Deploy from a branch ← اختر الفرع والمجلد `/ (root)`.
- **Netlify / Vercel / Cloudflare Pages:** اسحب المجلد أو اربط المستودع — بلا أي إعداد بناء.

> **قبل الإطلاق:** استبدل النطاق `https://www.maktabatalnokhba.com` في الصفحات و`sitemap.xml`
> و`robots.txt` (و`BASE_URL` في `scripts/build.py`) بنطاقك الفعلي، وضع معرّف ناشر AdSense
> في `ads.txt`، وحدّث بريد التواصل في صفحتي الاتصال والسياسات.
