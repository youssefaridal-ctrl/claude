# 🌟 منارة الثقة — Manarat Al-Thiqa

عيادة رقمية عربية متكاملة لبناء الثقة بالنفس وتطوير الكاريزما والتدريب القيادي — موقع ثابت (Static) لا يحتاج أي خادم خلفي، جاهز للنشر على GitHub Pages أو Netlify أو أي استضافة.

## ما الذي يقدمه الموقع؟

- **3 حقائب تدريبية تفاعلية** بتتبع يومي للتقدم:
  - 🌱 رحلة الثقة — 21 يوماً (63 مهمة عملية، مبنية على CBT وركائز براندن والتعرض التدريجي)
  - ✨ الكاريزما والحضور — 14 يوماً (نموذج الحضور/الدفء/القوة)
  - 🧭 القيادة الواثقة — 10 وحدات (متلازمة المحتال، التفويض، SBI، الأمان النفسي)
- **6 مقالات علاجية** معمّقة بتمارين عملية
- **اختبار تقييم الثقة بالنفس** (10 بنود، نتيجة فورية مع توصية برنامج)
- **نظام حسابات وتتبع**: تسجيل/دخول، لوحة تحكم، سلسلة أيام، أوسمة إنجاز — كل البيانات في متصفح المستخدم (LocalStorage، خصوصية كاملة)
- **حقائب مهنية للمدربين والمعالجين** (صفحة المختصين)
- **SEO/GEO كامل**: بيانات منظمة JSON-LD (Organization, Course, Article, FAQPage)، sitemap.xml، robots.txt، Open Graph، وصف وكلمات مفتاحية لكل صفحة

## البنية

```
├── index.html              الرئيسية
├── programs/               الحقائب التدريبية (فهرس + 3 برامج)
├── articles/               المكتبة العلاجية (فهرس + 6 مقالات)
├── assessment.html         اختبار تقييم الثقة
├── professionals.html      حقائب المختصين
├── register/login/dashboard.html   الحسابات والتتبع
├── about/faq/contact/privacy/terms/404.html
├── css/main.css            نظام التصميم (RTL)
├── js/app.js               المصادقة + بيانات البرامج + محرك التتبع
└── sitemap.xml, robots.txt
```

## التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## ملاحظات تقنية

- التخزين محلي بالكامل (LocalStorage) — لربط خلفية حقيقية لاحقاً، استبدل كائن `Auth` و`Progress` في `js/app.js` باستدعاءات API.
- قبل النشر على نطاقك: استبدل `https://www.manarat-althiqa.com` في وسوم canonical/sitemap بنطاقك الفعلي.

> ⚕️ المحتوى تثقيفي وتدريبي وليس بديلاً عن العلاج النفسي المتخصص.
